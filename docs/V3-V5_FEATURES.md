# V3–V5 功能说明：留存、社交、变现

本文说明第 V3（留存）、V4（社交）、V5（变现与统计）三个版本的设计取舍与实现位置。所有数值都集中在配置文件，改数字即可调整。

## V3 留存

| 功能 | 规则 | 代码 |
|---|---|---|
| 每日任务 | 每个本地日 3 个任务，由日期确定性生成（同一天任何设备一致）；每个任务单独领取经验，3 个都完成再领一次额外奖励；跨天自动换新，不惩罚、不清零其它进度 | `progress/ProgressConfig.ts`（`MISSION_POOL`、`selectDailyMissions`） |
| 每周挑战 | 周一刷新；主题按周轮换（对应 3 个收藏系列）；3 个递进目标；全部完成有周奖励和专属庆祝弹窗；保留最近 26 周历史；无需后端 | `generateWeekly`、`weekKeyOf` |
| 等级/经验 | `xpForLevel(L)=40·(L−1)·L/2`；经验只来自正常游玩 | `levelFromXp`、`LEVEL_TITLES` |
| 成就 | 10 个，事件驱动解锁，进度/详情/手动领取，解锁时弹窗 | `ACHIEVEMENTS` |
| 结算页 | 星级 + 本局经验 + 等级条 + 任务/周挑战/新成就摘要 + 一条“下一步”推荐 + 醒目的“下一张拼图” | `pages/ResultPage.ts` |
| 回访体验 | 首页显示等级/称号/今日任务进度，任务成就入口有可领取红点 | `pages/HomePage.ts` |

### 防刷经验
- 同一作品同一难度只有**第一次**完成有经验；之后只有**星级提升**才补差价（每星 8 点）。
- 每日挑战每天只给一次；每个好友挑战码只给一次；工坊照片作品不给经验。
- 事件键保存在 `progress.awarded`（上限 300，超出丢最旧），所以反复重玩不能刷。
- 任务、周目标、成就奖励都只能领一次（`claimed`）。
- 旧存档升级时用已有成绩一次性补算经验并写入事件键，重玩也不会重复发。

## V4 社交

- **好友挑战**沿用原有挑战码机制（无后端、校验和）；本版新增：结算页“再战一局”、挑战记录页（`HistoryPage`，每条可再战）。
- **本地与已验证严格区分**：挑战对比来自分享卡片，界面一律标注“本地对比”。
- **排行榜**：`social/LeaderboardService.ts`。
  - `LocalLeaderboard`：只显示玩家自己的成绩，标注“仅本机 · 未验证”，永远不造假玩家或名次。
  - `RemoteLeaderboard`：只有配置了 `RELEASE.leaderboardEndpoint` 且平台支持 `request` 才启用；只信任服务器返回的 `verified === true`；网络失败回退本地并说明。后端契约见 [leaderboard-backend.md](leaderboard-backend.md)。
- **分享卡片**：`ShareManager.shareCardOf(kind, …)` 统一生成结果/升级/成就/周挑战/收藏/名片卡（复用像素卡片绘制，微信走离屏 Canvas，Web 回退为文字分享）。每次点击记 `share_clicked`。
- **个人名片**：个人资料页可分享（只含等级、称号、收藏与成就数量，不含任何个人信息）。
- 不需要注册。

## V5 变现与统计

见 [ADS_SETUP.md](ADS_SETUP.md) 和 [ANALYTICS.md](ANALYTICS.md)。要点：广告默认关闭；激励视频只在玩家主动点击且平台确认看完时发奖励；插屏受 `AdPolicy` 约束，拼图中/教程中/前三局绝不出现。
